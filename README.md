# ⚖️ Denavy (The Engine of Space)

**LLM 에이전트의 코딩 행위를 제어하는 '공간과 이성의 법칙'입니다.**

Denavy는 거대 언어 모델(LLM)이 환각 없이 결정론적으로 시스템을 설계하고 코드를 작성하도록 강제하는 **무상태(Stateless) 기호 논리 언어**입니다.

### 🏛️ Core Identity
- **Cold & Stateless**: 과거의 기억이나 서사가 배제된 순수한 물리적/논리적 제약만을 제공합니다.
- **Symbolic Control**: 자연어의 장황함을 배제하고 8대 기호(`@`, `!`, `?`, `<-`, `=>` 등)를 통해 에이전트의 연산 경로를 완벽히 통제합니다.

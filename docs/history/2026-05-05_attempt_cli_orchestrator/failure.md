# Why Failed: CLI 기반 Denavy 오케스트레이터 구현

## 1. 직접 원인 (Immediate Cause)
- 구현 범위가 너무 커져서 중간에 멈춤
- 실제 동작 결과 없이 구조만 계속 확장됨

## 2. 근본 원인 (Root Cause)
- “완전한 하네스”를 한 번에 만들려고 함
- 최소 실행 단위 없이 전체 구조부터 설계
- 구현보다 설계에만 몰입하는 구조

## 3. 반복 패턴 여부
- Yes
- 이전 시도들도 동일하게:
  - 구조 설계 → 범위 확대 → 중단

## 4. 잘못된 판단
- RC1~RC9 전체를 동시에 고려함
- 오케스트레이터를 먼저 완성하려고 함
- “쓸 수 있는 최소 기능”을 정의하지 않음

## 5. 재발 방지 규칙
- 전체 구조 먼저 설계 금지
- RC 모듈 동시 도입 금지
- 반드시 “1시간 내 실행 가능한 결과”부터 시작
- 출력 없는 구조 설계 금지

## 6. 다음 시도 조건
- CLI에서 JSON 결과 1개 출력 가능해야 시작
- 실제로 내가 사용할 수 있는 수준이어야 함
- dry-run 기준으로만 동작하도록 제한

## 한 줄 교훈
- Denavy는 설계 프로젝트가 아니라, “작동하는 최소 도구”부터 만들어야 한다
